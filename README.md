# Laboratorio #3 Ejercicio 1- LibroCalificaciones 4 (Hojas Impresas)
**Fecha:** [22/09/2026]

## Contenido del Repositorio
En este problema se desarrollaron 2 clases y un metodo main, la primera clase LibroCalificaciones permite insertar una cantidad determinada de calificaciones y conseguir su promedio.
La segunda clase LibroCalificaciones1 Permite ingresar igualmente calificaciones y determinar su promedio pero este estara limitado por un sentinela, en esta caso -1 indicara al programa cuando terminar de leer las calificaciones. Ambas clases son llamadas por el main para mostrar como pueden darse diferentes tipos de entradas y obtener una salida.
